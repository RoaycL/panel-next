## v0.0.39 测试版

- 重构账号体系：新安装默认管理员为 `admin / admin123`，已有账号不覆盖；部署后请立即修改默认密码。
- Web 登录页与扩展登录弹窗支持注册，不要求邮箱，昵称可选；管理员可关闭注册，新账号仅获得普通用户权限。
- 新密码使用 bcrypt，旧密码成功登录时兼容升级；增加登录、注册限流与并发账号创建保护。
- 统一 Web 与扩展的小组件网格对齐、底部描述及最大 4×2 尺寸，优化天气、热榜和倒计时的尺寸适配。
- 补齐主题和声明式小组件包的导入、保存、删除、远程安装与更新；主题支持独立日间／夜间壁纸以及默认主题的双模式壁纸设置。
- 修复 Docker 发布凭据问题，发布镜像到 `ghcr.io/roaycl/panel-next`；提供扩展 ZIP 与 SHA-256 文件。

升级前备份数据库。密码迁移为 bcrypt 后，回退旧镜像需同时恢复升级前数据库备份。扩展 ZIP 不包含服务端，请同步更新后端。
