# v0.0.47

## 壁纸

- Wallhaven 图库新增“美女写真”“Cosplay”快捷分类。
- 搜索无结果时自动放宽筛选条件重新搜索，减少空白结果。

## 扩展编辑与布局

- 组件编辑栏移到卡片下方说明条，不再遮挡组件标题；分组标题旁新增“编辑布局”按钮，长按拖拽时有明显缩小反馈。
- 未手动排序的页面书签排在组件前，编辑模式新增“一键整理”，避免密集网格中书签被挤成单列。
- 一列或一行的小尺寸组件也能看到编辑与重试按钮。

## 菜单、分组与组件

- 书签与组件右键菜单的尺寸选项可预览占位大小，菜单改为不透明底色并自动保持在可视区域内。
- 书签菜单新增“复制链接”和“移动到”其他分组。
- 侧栏自动隐藏时，页面标题下方显示分组切换按钮。
- 内置组件标题统一字号与图标；天气、热榜加载失败时显示提示与重试按钮。

## 添加中心

- 组件包管理折叠到组件列表下方；网站图库改为紧凑图标网格，一键添加并标记已添加的网站。
- 组件管理拆分为“全局”和“当前分组”两部分；画布与右键菜单文案改为多语言。

## 升级提示

- 本版本仅含前端与扩展改动，服务端无需迁移。
