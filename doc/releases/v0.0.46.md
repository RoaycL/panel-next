# v0.0.46

## 启动与布局

- 扩展启动时提前绘制已保存壁纸，减少背景闪烁；应用切换壁纸后清理旧启动背景。
- 修复壁纸失败回退与快速切换竞态，首次打开按分组排序进入首个分组，改进无排序数据的回退顺序。

## 安全与服务

- 默认密码账号登录后必须先修改密码；新安装默认关闭注册，升级保留已有账号和注册开关。
- 加固上传、用户管理、公开接口和请求大小限制；服务器代抓取拒绝内网、回环与非公网地址，防止恶意访问服务内部网络。内网站点可使用本地上传图标。
- 旧 Token 兼容期截止 2026-11-07 00:00 UTC，旧客户端需升级或重新登录，第三方脚本改用 Bearer 会话。
- 修复 Docker 默认配置和版本号尾部换行，更新账号及部署文档、依赖和持续集成检查。

## 升级提示

- 升级前备份数据库及上传文件。默认密码账号需完成改密才能继续使用其他功能。
- 现有密码哈希可能升级，回退旧服务时应同时恢复升级前数据库备份。
