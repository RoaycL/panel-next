# v0.0.55

## 壁纸库

- 「Wallhaven 壁纸库」改名为「在线壁纸库」，顶部可在 Wallhaven、Bing 每日、Unsplash、Pexels、Konachan、yande.re 之间切换，记住上次选择的壁纸源。
- Bing 每日：最近 15 天的每日一图，4K 原图，无需 API Key。
- Unsplash / Pexels：支持搜索和快捷标签，预览时标注摄影师；需在「高级设置」填写自己的免费 API Key（仅保存在本机，按账号隔离）。
- Konachan / yande.re：按英文标签搜索，支持最新上传 / 评分最高 / 随机发现排序；内容分级 SFW / Sketchy / NSFW 可多选，默认仅 SFW；只显示宽度 1920 以上的横图。
- 所有壁纸源都支持预览、设为壁纸和加入「我的喜欢」。

## 服务端

- 新增 `GET /api/v1/widgets/wallpapers?source=bing|unsplash|pexels|konachan|yandere`，统一代理以上壁纸源并缓存 15 分钟；Unsplash / Pexels 的 Key 通过请求头 `X-Wallpaper-Api-Key` 传递，不放入 URL。

## 升级提示

- 此版本为测试版，无数据迁移。
- 服务端需能访问 cn.bing.com、api.unsplash.com、api.pexels.com、konachan.com、yande.re；浏览器需能加载对应图片域名。
