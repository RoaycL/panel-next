# v0.0.54

## 壁纸库

- 选中态改为磨砂玻璃样式（来源标签、内容分级、壁纸分类、快捷标签和搜索按钮），日间和夜间都清晰可读；修复夜间选中按钮白底白字看不清的问题。
- 内容分级从高级设置移到筛选栏，与排序方式、壁纸分类并排显示；SFW / Sketchy / NSFW 可多选，至少保留一项，NSFW 仍需配置 API Key。
- 新增「外部图床」栏：服务端已配置外部图床时，管理员可在壁纸库中分页浏览图床里的图片，点击即可应用或加入喜欢；未配置时不显示。

## 服务端

- 新增 `GET /api/imgbed/status`（登录可用）和 `GET /api/imgbed/list`（仅管理员），后者转发 CloudFlare-ImgBed 的 `/api/manage/list`。

## 升级提示

- 此版本为测试版，无数据迁移。
- 浏览图床列表需要图床 API Token 具备 list（读取列表）权限；只有 upload 权限时，「外部图床」栏会提示补充权限。
