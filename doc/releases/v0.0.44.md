# v0.0.44

## 访问与图标

- 新增「自动 / 公网 / 内网」访问模式，Web 与扩展均支持。自动模式检测浏览器能否访问内网地址，失败时回退公网；浏览器安全策略阻止检测时可手动选择内网。
- 修复编辑保存书签时图标短暂移位的问题，保留原分组内的位置。
- 改进网站图标获取，支持跳转、相对路径和页面声明的图标，限制下载时间与大小，拒绝错误 HTML 内容，并提供明确的失败提示。

## 最新设置同步

- 账号仅同步最新设置快照，不再保存多个历史版本；普通页面设置、布局、壁纸、壁纸喜欢、主题参数和访问模式一并同步。
- 离线修改合并为一份待同步快照，联网后重试；防止旧缓存覆盖尚未同步的修改。备份页面显示同步状态并支持重试。
- 登录凭据、服务器地址、API Key、搜索记录等敏感或设备专属内容不参与同步。第三方主题/插件安装包仍需在目标设备安装。
- 升级会清理旧的同步历史通知，不影响当前布局与设置。历史回滚取消，手动导入/导出备份仍可使用；升级前请备份服务数据。

## 壁纸库

- 扩大缩略图并调整搜索、筛选和结果区域间距，改善拥挤布局。
- 榜单名称仅使用中文，分级改为 SFW / Sketchy / NSFW 三个独立选项，非安全内容需要配置 Wallhaven API Key。

## 验证

- Web/扩展完整构建、设置同步、访问模式、图标位置、壁纸回归及 Go 测试通过。
- 浏览器预览验证了模式切换和同步状态设置；真实扩展安装及跨设备同步仍建议更新后复测。
