### 安装

下载 Assets 中的 `panel-next-extension-v0.0.29.zip`，解压后打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，再选择含 `manifest.json` 的文件夹。`.zip.sha256` 用于核对下载完整性。

GitHub 自动生成的 Source code 不是扩展安装包。如果新标签页仍显示 iTab，可临时停用 iTab，不必卸载。
