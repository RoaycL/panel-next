# v0.0.48

## 同步

- 本地修改改为静默同步，不再频繁误报“已在其他设备修改”的冲突提示。
- 写入按顺序串行提交，离线队列中的修改也保持原有顺序；云端有无关改动时自动合并后重试。
- 新增同步状态指示器，可随时查看同步进度与结果。

## 壁纸

- Wallhaven 图片可先预览再应用，预览支持键盘操作；原图加载失败时给出提示。
- Wallhaven 分类改为多选，默认全选；切换筛选条件后自动刷新结果。
- 壁纸选择器中隐藏公共图库。

## 扩展编辑与布局

- “一键整理”改为组件优先排列，仅在顺序确实会变化时才提供。
- 滚轮切换分组时侧栏会闪烁提示当前位置。
- 新增图标管理对话框；所有写入路径统一图标底色，夜间遮罩在不透明图片上也保持生效。
- 修复侧栏“分组排序”中保存、重置按钮被挤压变形的问题。
- 扩展搜索栏移除书签搜索。

## 图标

- 应用图标更换为新的便当格设计。
- Go 服务端新增 PWA 与 apple-touch 图标路由，修复 Docker 与二进制部署下图标 404。

## 升级提示

- 服务端新增图标静态路由，Docker 与二进制部署请升级到本版本镜像或程序；无数据迁移。
