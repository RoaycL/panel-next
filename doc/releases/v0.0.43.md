# v0.0.43

## 自动检查扩展更新

- 每次打开扩展新标签页、浏览器启动和扩展安装/更新时检查 GitHub Releases，后台每 10 分钟检查一次。
- 新版提示提供扩展包下载、更新说明及“暂不提醒”。“关于”页支持手动检查，显示当前扩展版本和上次成功检查时间。
- 支持当前测试版发布，仅提示已上传 ZIP 和校验文件的更高版本。离线保留最后结果，GitHub 限流时延迟重试，不自动安装或执行远程代码。
- 新增 `alarms` 及 `https://api.github.com/*` 权限；更新请求不携带账号、令牌或服务器配置。现有用户需先安装本版，之后才能使用自动检查。

## 加载与稳定性

- 扩展首屏不再等待旧登录迁移和令牌刷新，先恢复当前服务器/账号的本地快照，再后台同步。
- 新增浅/深色加载壳，避免脚本启动期间的无样式白屏。
- 图标优先读取本地缓存；未命中时直接显示原图，缓存下载不阻塞显示。跳过未授权第三方图片的跨域缓存请求，保留已缓存图片的离线读取。
- 登录迁移/刷新增加 8 秒超时，普通 API 默认 15 秒，同步长轮询单独使用 35 秒超时。
- 调整设置弹窗自动聚焦与关闭时焦点处理，保留 Tab 导航和 Esc 关闭后的焦点返回。

## 验证说明

- 更新识别、后台定时/启动、图标缓存和首屏回归测试，以及 Web/扩展构建通过。
- 隔离浏览器验证访客首屏与弹窗键盘交互；真实安装环境的加载耗时仍需复测。
