# v0.0.42

## 功能精简

- Web 与扩展统一移除 Docker 容器管理入口、页面及容器控制接口，不再需要 Docker Socket 挂载。Docker 部署与系统监控仍保留。
- 移除预设头像选择，保留自定义头像上传、头像地址和现有用户头像。
- 移除多端会话管理页面及管理接口，保留登录续期、退出登录、改密失效和账号停用保护。不删除用户资料、书签或壁纸。

## 修复

- Wallhaven 分页计数兼容整数与数字字符串，修复配置 API Key 后可能出现的 `meta.per_page` 解析报错。
- 为数字/字符串混合响应、无效计数以及已移除管理接口添加回归测试。

## 下载与升级

- 扩展包：`panel-next-extension-v0.0.42.zip`；校验文件：`panel-next-extension-v0.0.42.zip.sha256`。
- Docker 镜像：`ghcr.io/roaycl/panel-next:0.0.42`。
- 旧配置中若仍挂载 `/var/run/docker.sock`，可移除该挂载；现有登录安全机制和数据存储结构不变。
