## v0.0.30 测试版

- 修复书签图案偏移、被裁切：图标内容跟随实际外框尺寸，不再在 54px 外框中绘制固定 64px 表面。
- 修复 721–1000px 宽度下书签格子过窄的问题，保留共享组件网格和已保存布局，不迁移用户数据。
- 提高首页功能栏与设置导航的文字对比度和字号；选中状态不再只靠低对比度绿色文字表达。
- 修复账号头像被姓名首字覆盖：登录后显示真实头像，访客、加载中及图片失败时使用本地用户图标，头像预览也沿用同一逻辑。
- 图库的上传类型、上传和清理按钮保持横向排列；手机宽度也可同排，清理按钮保留确认步骤并提高文字对比度。

### 下载和更新

在 Assets 中下载 `panel-next-extension-v0.0.30.zip`，不要下载 Source code。`.zip.sha256` 用于核对下载完整性。

先备份重要数据，将新包解压覆盖到原来的扩展目录，在 `chrome://extensions` 点击“重新加载”，然后新建标签页。无需卸载旧扩展，以免清除本地偏好和缓存。

### 验证范围

已检查本地预览的明暗模式、390px 与 768px 布局、12 个预设图标的中心位置、真实账号头像及加载失败兜底；未保存账号资料或修改云端书签。真实 Chrome 安装和重启持久化仍需要实测。
