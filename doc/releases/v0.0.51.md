# v0.0.51

## 天气

- 天气组件改为 Apple 天气风格，背景随天气状况变化。
- 服务端天气接口新增逐小时预报、日出日落和紫外线指数，详情页同步展示。

## 热搜

- 热搜组件重新设计：按来源品牌配色，按组件尺寸自动调整布局。
- 服务端热搜接口新增标签、摘要和配图字段。

## 组件放大视图

- 日历、待办、便签、倒计时和时钟重新设计放大视图。
- 放大后组件保留自身外观，弹窗背景透明，不再显示白色卡片。

## 下班倒计时

- 下班倒计时支持工作日、发薪日与节假日，并新增可实时预览的设置面板。

## 夜间模式

- 夜间玻璃效果更深、更通透，接近 iTab 暗色模式。
- 右键菜单在日间和夜间都使用悬浮玻璃样式。
- 新增夜间调暗遮罩，可用滑块调节对壁纸、图标和组件的调暗程度。

## 升级提示

- 服务端天气与热搜接口新增字段，Docker 与二进制部署请升级到本版本镜像或程序；无数据迁移。
