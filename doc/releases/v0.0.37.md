## v0.0.37 测试版

- 透明图片图标也保持固定的圆角方框边界，超出边界的内容会裁切；保留“无背景”选项，图片加载成功后不显示底层备用字母。
- 更新图标文字阴影和悬浮效果，仅图标在悬浮时浮起，保持名称位置稳定。
- 同步状态徽标移到首页右上角，避免状态变化影响侧栏布局。
- 包含 v0.0.36 的多窗口存储更新与重载修复，以及首页控制入口精简。

### 验证边界

事务式打包流程执行版本校验、项目检查、类型检查及 Web／扩展完整构建，验证 Manifest V3 并生成 ZIP 和 SHA-256 校验文件。真实 Chrome 安装和多窗口账户同步仍需实装验收。

### 安装更新

下载 Assets 中的 `panel-next-extension-v0.0.37.zip`，解压到原扩展目录，在 `chrome://extensions` 重新加载，再打开新标签页。无需卸载已有扩展。对应的 `.zip.sha256` 文件用于校验安装包完整性。
