## v0.0.35 测试版

- 修复透明图片图标露出底层备用字母的问题：图片加载成功后移除备用图标，加载失败时仍可回退。
- 图标编辑器增加“无背景”按钮；用户选定的底色优先于网站预设，透明模式保留图片比例和完整轮廓。
- 修复自定义头像保存后被旧账户快照覆盖的问题：保存后回读账户资料并更新本地快照，增量同步单独刷新账户资料。后台更新不会丢弃未保存的头像草稿；保存结果不一致时保留编辑内容并提示错误。
- 调整组件混排布局：组件四边与所占行列的图标边缘对齐，组件标题放在独立区域；改善笔记本与窄屏的网格布局。

### 验证边界

通过类型检查、修改文件的代码检查、主题及品牌图标验证、头像上传与账户快照测试、响应式及架构校验、Web／扩展完整构建。隔离浏览器验证透明图片、加载失败回退、背景色覆盖，及头像上传、保存请求、快照、增量刷新和整页重载恢复。1784px、1440px、900px、390px、320px 下组件四边对齐误差小于 1px。

浏览器验证使用模拟 Chrome Storage 与服务响应，未修改真实账户；真实 Chrome 安装、账户服务和云端同步仍需实装验收。

### 安装更新

下载 Assets 中的 `panel-next-extension-v0.0.35.zip`，解压到原扩展目录，在 `chrome://extensions` 重新加载，再打开新标签页。无需卸载已有扩展，避免丢失本地配置。编辑图标时点击“无背景”即可取消底色。对应的 `.zip.sha256` 文件用于校验安装包完整性。
