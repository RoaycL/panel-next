# v0.0.56

## 壁纸库

- 移除 Unsplash 和 Pexels 两个壁纸源（需要个人 API Key，申请门槛高）；在线壁纸库保留 Wallhaven、Bing 每日、Konachan、yande.re。
- 修复 Konachan 提示「API Key 未配置或无效」的问题：Konachan 不需要 Key，这是服务端访问 konachan.com 被拒（HTTP 403）时的误报。现在被拒时会自动改用 konachan.net 镜像（仅 SFW 内容）。
- 其他壁纸源被拒时，提示改为说明是服务端所在网络被对方拦截，不再要求填写 Key。

## 服务端

- `GET /api/v1/widgets/wallpapers` 的 `source` 现在只接受 `bing`、`konachan`、`yandere`；不再读取 `X-Wallpaper-Api-Key` 请求头。

## 升级提示

- 此版本为测试版，无数据迁移。
- 使用 Konachan 时，服务端需能访问 konachan.com 或 konachan.net；浏览器需能加载对应的图片域名。
