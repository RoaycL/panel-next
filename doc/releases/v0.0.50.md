# Panel Next v0.0.50 测试版

- 小组件支持点击空白区域或展开按钮查看详情，可切换全屏，按 Esc 或点击关闭按钮返回桌面。
- 热搜卡片去除顶部重复标题，默认显示四条资讯；展开后显示完整榜单（最多 50 条），支持切换来源和刷新。
- 天气详情展示体感温度、风速、更新时间和接口提供的完整每日预报，窄屏可横向查看预报。
- 展开与关闭复用同一个组件实例，保留便签内容和已选择的热搜来源；编辑模式下不触发展开。
- 包含最新主分支的品牌图标、新建分组与组件显示修正。

本版本为测试版。天气详情仅展示现有接口提供的数据，不包含逐小时预报或空气质量。

## 安装

下载 `panel-next-extension-v0.0.50.zip`，解压后在 Chrome / Edge 扩展管理页面启用开发者模式，选择“加载已解压的扩展程序”。已有用户更新扩展文件后重新加载扩展。

## 验证

完整构建与项目验证、类型检查和扩展包校验通过；使用模拟数据验证桌面与窄屏、热搜详情切换、全屏、关闭恢复和便签内容保留。
