## v0.0.38 测试版

### 界面与图标

- 将扩展的新界面同步到 Web 端，统一日间白、夜间黑的主题及磨砂玻璃材质；设置顶部与侧边栏使用相同质感。
- 优化首页排版、文字阴影、图标悬停及夜间展示，修复图片图标圆角裁切，保留品牌图案辨识度。
- 重新设计自定义图标编辑布局、实时预览和背景颜色选择。
- 优化图库素材中心的筛选、搜索及卡片布局；壁纸独立放入设置页面。
- 增加分组图标设置，提供 80 个分类本地图标及搜索，支持文字、图片和 SVG 图标。
- Web 端采用统一的添加入口与弹窗登录，保留账号管理、站点设置等管理功能。

### 同步与可靠性

- 补充壁纸同步与本地偏好处理，优化离线队列合并、回放锁和并发写入保护。
- 增加分组外观、壁纸同步及磨砂材质一致性的回归检查。

### 安装更新

本地已通过完整构建流程、类型检查、改动文件代码检查、主题与图标缓存测试，并完成扩展包完整性及 SHA-256 校验。日间和夜间页面已进行浏览器截图检查。

下载 Assets 中的 `panel-next-extension-v0.0.38.zip`，解压后在 `chrome://extensions` 中加载已解压扩展；更新时替换原目录文件并点击重新加载。附带 SHA-256 校验文件。

本版本为测试版。Web 服务需要更新对应镜像或重新部署代码；发布本身不会自动修改现有服务器。
