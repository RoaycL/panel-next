# v0.0.58

## 新标签页

- 修复登录后刷新新标签页时，会先闪一下「常用推荐」分组再滑到自己的分组。现在启动和同步时直接替换内容，只有手动切换分组才有滑动动画。
- 修复从放大视图关闭小组件时，留下一条黑色描边残影。小组件会等关闭动画结束后再回到网格。

## 其他

- 修复打开弹窗时 Chrome 控制台出现的 `Blocked aria-hidden on an element because its descendant retained focus` 警告（给 Naive UI 依赖的 vueuc 打了补丁）。

## 升级提示

- 此版本为测试版，无数据迁移。
- 自行构建 Docker 镜像时，Dockerfile 现在会在安装依赖前复制 `pnpm-workspace.yaml` 和 `patches/`。
