## v0.0.34 测试版

- 全面更新扩展界面：雾白、松绿与石墨绿构成低饱和配色，统一字体、圆角、边框、阴影和键盘焦点。
- 首页重新整理时钟、搜索、分组标题、添加及编辑入口；侧栏和窄屏布局更清晰，新用户默认使用纯色画布，已有壁纸设置保留。
- 设置、添加中心、组件预览、主题预览、搜索结果与通知使用一致的视觉样式，改善深色模式及减少动态效果偏好下的体验。
- 扩展默认主题独立配置；网页端配色、外部主题和用户自定义主题覆盖继续有效，保留书签、组件、账户及同步接口。

### 验证边界

通过类型检查、修改文件的代码检查、主题与响应式验证、扩展持久化测试及 Web/扩展构建。隔离浏览器预览验证明暗切换、设置导航、侧栏、书签搜索、添加便签及月历、刷新恢复，以及 320px/390px/768px 布局。预览使用模拟 Chrome Storage 和服务响应，真实 Chrome 安装、权限及账户云同步仍需实装验收。

### 安装更新

下载 Assets 中的 `panel-next-extension-v0.0.34.zip`，解压到原扩展目录，在 `chrome://extensions` 重新加载，再打开新标签页。无需卸载已有扩展，避免丢失本地配置。对应的 `.zip.sha256` 文件用于校验安装包完整性。
