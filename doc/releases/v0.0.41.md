# v0.0.41

包含 v0.0.40 的全部界面与功能更新，并修复上线复查发现的跨域请求问题。

## 修复

- 修复扩展设置 Wallhaven API Key 后，跨域预检请求被服务端拒绝的问题。
- 跨域校验与响应使用同一份请求头白名单，避免两处配置不一致。
- 保留原有来源和请求方法限制，并增加相关回归测试。

## 下载

- 扩展包：`panel-next-extension-v0.0.41.zip`。
- 校验文件：`panel-next-extension-v0.0.41.zip.sha256`。
- Docker 镜像：`ghcr.io/roaycl/panel-next:0.0.41`。
