## v0.0.36 测试版

- 修复多窗口同时打开扩展导致的循环重载闪屏与掉线问题：
  - 优化跨窗口存储事件监听逻辑，仅在实际登录状态改变（登录、退出或切换账号）时执行整页重载；同账号凭据更新与刷新在内存中静默同步。
  - 增加状态与存储适配器写入去重，避免重复向浏览器存储写入相同数据触发广播风暴。
- 精简首页控制入口，打造极简工作区：
  - 左上角「Panel Next」品牌图标升级为交互按钮，点击可直接呼出系统与个人设置中心。
  - 移除主界面冗余的右上角「自定义你的空间」、中间右侧「添加/编辑组件」以及页脚「更换壁纸」按钮，相关功能统一整合入设置面板或右键上下文菜单。
- 优化侧边栏可访问性，移除可能与元素焦点冲突的 `:aria-hidden` 属性，消除 Chrome 控制台警告。

### 验证边界

通过全部项目构建与测试套件（包括版本校验、架构边界、状态 UI、响应式 UI、离线同步、扩展持久化与类型检查），完成 Web 端与扩展端打包构建并成功生成 `panel-next-extension-v0.0.36.zip`。

### 安装更新

下载 Assets 中的 `panel-next-extension-v0.0.36.zip`，解压到原扩展目录，在 `chrome://extensions` 点击重新加载扩展即可。
