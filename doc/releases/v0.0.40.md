## v0.0.40 测试版

- 图标编辑支持 50%–200% 缩放、一键填满和重置，保持圆角裁剪；背景颜色填满选择框。
- 修复分组图标库溢出，增加分组拖动排序和上下移动；首页隐藏旧「系统」分组入口，原数据保留。
- 扩展分组切换增加方向一致的上下滑动过渡，支持滚轮循环切换和减少动态效果设置。
- 修复扩展个人／公共图库图片路径，壁纸预加载成功后再应用；失败保留旧背景，快速切换不会被旧请求覆盖。
- Wallhaven 支持本机保存 API Key、内容范围和分类筛选；密钥通过请求头转发，不放入 URL，账号密钥缓存隔离并阻止携带密钥跳转。
- 壁纸库增加喜欢按钮和「我的喜欢」，支持应用、取消收藏、去重与保存失败提示。
- 搜索框去除原生历史下拉和输入边框，统一磨砂历史面板；开启「保留搜索历史」后点击查看最近 10 条，支持填入、删除、清空、键盘操作。关闭开关清除本机历史并停止保存。

「我的喜欢」、搜索历史与 Wallhaven API Key 为本机数据，不跨设备同步；收藏保存图片地址，不是原图离线下载。API Key 请仅通过可信的 HTTPS Panel Next 服务使用，具体内容仍以 Wallhaven 账号权限为准。

下载 `panel-next-extension-v0.0.40.zip`，解压后在浏览器扩展管理页选择「加载已解压的扩展程序」。更新已安装扩展时，请使用新包覆盖原安装目录后重新加载；保留原目录有助于保留扩展标识和本机设置。提供 SHA-256 校验文件。

新增图标缩放和 Wallhaven API Key 需要新版服务端支持。升级前备份数据库与上传文件；本版本不修改已有账号或密码。
