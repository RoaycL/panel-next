## Chrome 扩展下载与安装

本版本的 Assets 附带 `panel-next-extension-v<版本号>.zip` 和对应的 `.zip.sha256` 校验文件。GitHub 自动生成的 Source code 是源码，不是扩展安装包。

1. 下载扩展 ZIP 并解压到固定目录，不要只在压缩包预览中打开。
2. 打开 `chrome://extensions`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
4. 新建标签页；如果仍显示 iTab 等其他新标签页扩展，可临时停用它们，无需卸载。
5. 未登录可使用预设页面；登录与云端同步通过设置中的“服务器节点连接”配置服务器地址。

更新已加载的扩展时，先备份重要数据，将新版本解压覆盖到原来的固定目录，再在扩展管理页点击“重新加载”，不要先卸载旧扩展，以免清除本地偏好与缓存。

测试版本尚未在 Chrome Web Store 发布。扩展 ZIP 不包含服务端，新增服务端能力需要部署对应版本的后端。
