# 最新状态同步与书签访问模式

设置中的「书签访问模式」提供自动、公网、内网三档，Web 和扩展均可选择。自动模式从当前浏览器探测内网网页或默认图标，只把成功响应视为可达，失败或 1.8 秒超时后使用公网地址，结果缓存 60 秒。浏览器的私有网络权限、混合内容限制或网站验证可能阻止探测；这时可强制内网。没有内网地址时使用默认地址，右键“打开局域网地址”仍然是明确的内网访问。

登录后，普通个人设置按账号和服务器同步最新状态：面板外观、主题选择及日夜壁纸、网络模式、语言和明暗模式、扩展搜索/时钟/侧栏偏好、书签尺寸与分组内的小组件布局及配置、壁纸喜欢。书签、分组、排序和资料继续使用账号下的当前数据。不同端支持的界面功能可能不同，但对应的偏好不会因为换端而被清空。

API Key、登录令牌、密码、服务器连接地址、搜索关键词、设备探测结果、组件本地清理任务及插件/主题的可执行安装包不复制到其他设备。主题选择和参数可同步，但其他设备需要安装对应的主题或插件才能使用。

设置在本机保存后写入一份按服务器/账号隔离的最新待同步状态，后续修改覆盖同一待同步槽位。连接恢复或每 30 秒重试，不为每次修改生成历史副本；新设置不能被旧缓存覆盖。云端先读取当前状态并验证同步标记，再写入，冲突时重新读取并有限重试。普通设置最大 800 KB，超限会在同步页提示并保留本机数据。

服务端只保留每个账号的最新变更通知，实际内容以当前业务表为准；启动时清理旧通知。单调递增的同步标记仅用于唤醒刷新和防止并发丢写，不支持回滚。扩展每次刷新获取最新完整快照，不逐个重放云端历史版本。旧客户端发现标记不连续时仍可降级读取完整快照。

本机布局历史不再生成，原有历史缓存会被清理，旧历史无法回滚。手动导出与导入备份仍可使用。发布或部署前应照常备份数据库和上传文件。
