# Panel Next 隐私政策

> 最后更新：2026-08-21
> 适用对象：使用 Panel Next 自托管服务的最终用户

## 1. 概述

Panel Next 是自托管（self-hosted）的导航面板服务。您可以（并且通常应该）在自己的服务器、域名或内网中部署它。**您的数据存储在自己的服务器上**，本项目开发者与运营方不收集、不传输、不存储您的任何数据。

自托管意味着数据流经您自己控制的服务器与您自己的设备（浏览器 / Chrome 扩展）之间，仅此而已。

## 2. 我们收集的数据

由于是自托管，Panel Next 服务端本身不向任何第三方上报数据。服务端保存的数据完全取决于您的部署与使用，主要包括：

| 数据类型 | 说明 | 存储位置 |
| --- | --- | --- |
| 账号信息 | 用户名、密码哈希、昵称、头像、邮箱、角色 | 您服务器的数据库（`user` 表） |
| 面板配置 | 分组、卡片、壁纸、搜索引擎、组件布局、个性化设置 | 您服务器的数据库（`item_icon_group`、`item_icon`、`user_config` 等表） |
| 上传文件 | 您上传的图片、图标、壁纸 | 您服务器的文件系统（`source_path` 目录） |
| 设备会话 | 登录设备 ID、Token 哈希、最后活跃时间 | 您服务器的数据库（`user_session` 表） |
| 同步状态 | 增量同步 revision 与变更日志 | 您服务器的数据库（`user_sync_state`、`user_sync_change` 表） |
| 访问日志 | 服务端访问记录（含来源 IP） | 您服务器运行目录的日志文件 |

**客户端本地数据**（浏览器 / Chrome 扩展）：
- 服务器地址、设备 ID、登录会话 Token、最近同步缓存（本地存储 / `chrome.storage.local`）
- 这些数据只保存在您的设备上，不会同步到第三方

## 3. 数据用途

- **面板展示与编辑**：在您的设备间同步分组、卡片、壁纸与个性化配置
- **身份验证**：校验登录、维持设备会话、实现多设备撤销
- **在线同步**：让 Web 与 Chrome 扩展共享同一套数据

Panel Next **不会**：
- 向任何第三方出售、出租或共享您的数据
- 在你的服务器之外存储账号或面板数据
- 在扩展中加载或执行远程代码

## 4. 第三方数据源

部分可选组件（如天气、热搜）会从第三方公开接口拉取公开数据。此类请求由您自己的服务端代理，仅用于展示公开内容，不提交您的个人信息。组件配置（如城市、数据源偏好）保存在您自己的服务器。

## 5. 数据存储与安全

- 密码以不可逆哈希（多重 MD5）存储，服务端不保存明文密码
- 登录 Token 仅以 SHA-256 哈希形式存储，服务端不保存原始 Token
- 备份文件包含您的全部数据，请妥善保管备份 ZIP（`panel-next-backup-*.zip`）
- 生产部署建议启用 HTTPS（原生 HTTPS 或反向代理），并修改示例配置中的默认密码

## 6. 账号删除

管理员可在「账号管理」中删除任意账号。删除操作会在同一事务中移除：

- 该账号的登录凭据（`user`）
- 面板配置、搜索引擎（`user_config`）
- 分组与卡片（`item_icon_group`、`item_icon`）
- 模块配置（`module_config`）
- 设备会话与刷新令牌（`user_session`、`user_session_refresh_token`）
- 同步状态与变更日志（`user_sync_state`、`user_sync_change`）

> 说明：删除账号**不会**自动删除该账号在公共图库（`public_file`）中上传的文件；公共资源由管理员统一维护。删除账号产生的文件记录保留与否由部署者决定（当前实现不删除 `file` 表中记录对应的磁盘文件，仅移除账号归属）。

普通用户如需删除自己的账号，请直接联系您的部署管理员操作。

## 7. 数据导出

管理员可通过「备份与恢复」应用下载完整备份 ZIP，其中包含：

- 数据库快照（或 MySQL/PostgreSQL 逻辑数据）
- 上传目录（`uploads`）
- 全局自定义样式目录

备份文件可用于迁移或恢复。
