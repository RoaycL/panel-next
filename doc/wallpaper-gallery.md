# 壁纸图库与 Wallhaven

「选择壁纸」中的个人／公共图库和 Wallhaven 卡片提供喜欢按钮，点击爱心不会应用壁纸。喜欢的图片按收藏时间倒序集中到「我的喜欢」，可点击应用或取消喜欢，最多 200 张。同一图片的站内路径和完整地址不会重复收藏。

喜欢列表按 Panel Next 服务与账号隔离，访客保存在本机，登录后随最新个人设置同步。Web 与扩展均支持，但不向 Wallhaven 账号提交收藏。收藏保存的是图片地址和缩略图信息，不是原图离线下载；图片被删除或网络不可用时仍可能无法加载。

个人和公共图库的站内图片地址由当前 Web／扩展运行环境解析，扩展会使用已连接服务的地址，不使用新标签页的扩展 Origin。失效图片显示错误与重试入口。

选择图片时先加载原图，加载成功后再应用。首页切换也等待新壁纸加载成功；失败或超时保留原壁纸并提示错误，快速切换时不会让较早请求覆盖较晚选择。慢网络、失效链接或图片服务器访问限制仍可能导致失败。

在「选择壁纸 → Wallhaven 壁纸库 → Wallhaven 账号 API Key」输入 Key，点击「保存到本机」。Key 从 Wallhaven 账号设置获取，不是账号密码。内容分级为三个独立档位：SFW（安全）、Sketchy（中间级）、NSFW（成人，需配置有效 Key），不混合其他级别；还可选择综合／动漫／人物分类。具体内容仍以 Wallhaven 权限为准。排序选项仅显示中文，搜索与筛选分行展示，缩略图采用自适应横向卡片。

Key 仅保存在当前浏览器、当前 Panel Next 服务与账号范围内，不参与布局同步。它使用请求头发送给连接的 Panel Next 服务，并由服务转发到 Wallhaven；不会加入 URL 或缓存键明文。仅连接可信的 HTTPS 服务。不同 Key 的搜索缓存隔离，含 Key 的上游请求不跟随跳转；「清除」移除本机 Key 并恢复安全内容筛选。

API Key 是敏感信息，本机存储不是加密保险库；共享浏览器前请清除 Key，在 Wallhaven 侧撤销或更换已泄露的 Key。
