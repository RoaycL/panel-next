# Panel Next 账号体系

## 首次安装与升级

Docker 及原生服务在数据库中没有任何用户时创建管理员 `admin / admin123`，不设置邮箱。请立即修改默认密码，对公网使用 HTTPS。升级不会改名、重置已有账号或密码，也不会改变原有注册开关。

新安装默认开放注册，管理员可在「站点设置 → 账号与注册」关闭。旧安装若此前关闭注册，需要管理员手动开启。注册不需要邮箱、邮件服务、验证码邮件或邀请码；个人资料中的邮箱只是可选联系信息，不是登录身份。

## 注册与登录

登录页及扩展内的登录弹窗共用注册表单，无需离开当前页面。

- 用户名：3–32 位字母、数字、下划线、点或短横线，以字母或数字开头。沿用数据库原有用户名大小写比较规则，不擅自重命名旧账号。
- 密码：6–50 个 UTF-8 字节，不允许全为空白；不自动去除空格或末尾标点。
- 昵称：可选，最多 15 个字符。留空使用用户名（长用户名截取前 15 个字符）。
- 自助注册仅创建已启用的普通用户，不接受角色、用户 ID、会话或管理员权限参数。
- 注册成功后回到登录表单，不在注册响应中返回密码或会话令牌。

`POST /api/v1/accounts/register`：JSON 请求 `{ "username": "alice", "password": "your-strong-password", "name": "Alice" }`；成功返回 `{ "code": 0, "data": { "id": 2, "username": "alice" } }`。`name` 可省略，邮箱无需传入。关闭注册返回业务码 `1700`，用户名已占用返回 `1701`。

管理员通过 `GET/POST /api/v1/accounts/settings` 查询/更新 `{ "openRegister": true }`。登录页通过既有 `/api/openness/loginConfig` 获取注册状态；配置读取失败时不允许注册。

## 安全与兼容

新建、修改及重置密码使用 bcrypt。旧版 MD5 密码在成功登录后按比较并交换方式升级，不清空设备会话；旧的邮箱格式用户名仍可登录。扩展继续使用独立的设备会话和本地保存，不回退到原始永久 Token 登录。退出、撤销设备或修改密码仍会使相应会话失效。

部署升级前请备份数据库。旧密码哈希升级为 bcrypt 后，旧镜像无法识别它；回退旧版本需要恢复升级前的备份，不能仅替换镜像。
历史账号如果使用超过 72 字节的密码，继续兼容旧哈希直到主动改密，不会截断密码导致账号无法登录。

注册请求最多 8 KiB；服务进程按直接连接 IP 限制每 10 分钟 5 次注册尝试，登录限制每分钟 20 次。不会信任任意客户端伪造的转发 IP。反向代理后的用户会共享代理 IP 的额度；公网部署应另外在受信任代理层配置限流。多副本部署需额外的共享限流器；账号创建采用数据库事务锁避免并发创建同名账号。

命令行 `-password-reset` 将第一个管理员的密码重置为 `admin123`，并撤销该管理员的全部设备会话；该命令不会把已有用户名改成 `admin`。请在本机维护时使用并立即改密。
