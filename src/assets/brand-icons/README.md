# Bundled website icons

These are original website favicons or brand assets downloaded from the official websites and brand channels. They are not redrawn substitutes. `sources.json` records every source URL, retrieval date and SHA-256 digest.

Brand names and logos belong to their respective owners. They identify links to those services; they do not imply endorsement or affiliation with Panel Next. Follow each owner's brand guidelines when redistributing or using these assets elsewhere.

Refresh manually with `node scripts/sync-brand-icons.mjs --refresh`. The extension never invokes this script and never downloads these icons at startup. Existing verified files are retained when a source is unavailable.

Special official sources:

- ChatGPT: https://help.openai.com/en/articles/7905742-what-does-the-official-chatgpt-ios-app-icon-look-like
- npm: https://github.com/npm/logos/tree/master/npm%20square
